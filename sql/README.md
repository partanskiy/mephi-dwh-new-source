# SQL-решение

Папка подготовлена для следующего этапа работы. Скрипты решения пока
не написаны и в учебной БД не выполнялись.

Планируемые файлы:

| Файл | Назначение |
|---|---|
| `01-load-dwh.sql` | Загрузка из `source1`, `source2`, `source3` и `external_source` в измерения и факты `dwh` |
| `02-create-customer-datamart.sql` | DDL витрины по заказчикам и таблицы учёта загрузок |
| `03-update-customer-datamart.sql` | Инкрементальный расчёт витрины |
| `04-check-results.sql` | Проверки полноты, уникальности, показателей и повторной загрузки |

После реализации в основном README появятся порядок запуска и результаты
проверок. Исходные SQL-примеры курса находятся в
[`../assignment/reference-sql/`](../assignment/reference-sql/).
