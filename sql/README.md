# SQL-решение

Скрипты рассчитаны на PostgreSQL 15 или новее. Каждый рабочий скрипт
выполняется в своей транзакции.

| Порядок | Файл | Назначение |
|---|---|---|
| 1 | [`00-create-order-fact.sql`](./00-create-order-fact.sql) | Создать отсутствующую f_order и обеспечить уникальность бизнес-ключей DWH |
| 2 | [`02-create-customer-datamart.sql`](./02-create-customer-datamart.sql) | Создать витрину по заказчикам и журнал успешных загрузок |
| 3 | [`01-load-dwh.sql`](./01-load-dwh.sql) | Загрузить четыре источника в измерения и факты |
| 4 | [`03-update-customer-datamart.sql`](./03-update-customer-datamart.sql) | Пересчитать затронутые пары заказчик-месяц |
| 5 | [`04-check-results.sql`](./04-check-results.sql) | Полностью сверить источники, DWH и витрину |

Первые два шага нужны при подготовке БД. Регулярный запуск: загрузка DWH,
обновление витрины, проверка. Повторный запуск DDL этой версии сохраняет
таблицы и данные; произвольные старые схемы он не мигрирует.

01-load-dwh.sql требует наличия external_source.craft_products_orders
и external_source.customers. Их структура ожидается по заданию;
реальные таблицы нового источника в предоставленной БД пока отсутствуют.
Скрипты не создают подмену этого источника.

Параметры подключения, команды запуска и ограничения описаны в
[`../README.md`](../README.md). Исходные примеры курса сохранены в
[`../assignment/reference-sql/`](../assignment/reference-sql/).
